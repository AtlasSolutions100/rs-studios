Campaignify has a remote MCP server, so you can use your workspace from Claude and other apps that speak the Model Context Protocol. Ask for ad copy, a campaign plan or a competitor snapshot, price a batch of image ads or AI presenter videos, and make them once you agree to the price, all from a chat.

Server address: {{ url }}

New to this? The Campaignify MCP page has example prompts and a step-by-step walkthrough.

Connect Claude.ai (web, desktop and mobile)

  1. In Claude, open Customize, then Connectors.
  2. Click + Add, then Add custom connector.
  3. Name it Campaignify, paste {{ url }} as the server URL and click Continue.
  4. Keep the settings Claude detects (sign in with OAuth, register automatically) and click Add.
  5. Log in to Campaignify if asked and choose whether Claude may spend credits.

On a Team or Enterprise plan, an owner adds it under Organization settings, Connectors (Add, Custom, Web), then each member clicks Connect under Customize, Connectors and logs in with their own Campaignify account. On Claude's Free plan you can add one custom connector.

Disconnect it any time in Campaignify under Settings, MCP access.

Turn it on in a chat

In a chat, click +, then Connectors, and switch Campaignify on. Then ask in plain words, for example:

  • "How many credits do I have, and which tools does my plan include?"
  • "Price 3 image ads for my best product in square and vertical, with the headline: <your headline>"
  • "Write 5 Meta ad variants for my product."
  • "Plan a 2-week test for my product at $30 a day on Meta and TikTok."
  • "Give me download links for everything made this week."

Claude shows the credit total and asks before it makes anything. To stop a tool entirely, open the connector under Customize, Connectors and set that tool to Blocked.

Claude Code

Sign in with your browser:

claude mcp add --transport http campaignify {{ url }}

Then run /mcp in Claude Code and pick Campaignify to sign in. Or use an API key:

claude mcp add --transport http campaignify {{ url }} \
  --header "Authorization: Bearer YOUR_CAMPAIGNIFY_KEY"

Claude Desktop config file and other clients

Most clients can add a remote server by URL and sign in. If yours only runs local servers, the mcp-remote bridge works with an API key. In claude_desktop_config.json:

{
  "mcpServers": {
    "campaignify": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ url }}",
               "--header", "Authorization: Bearer ${CAMPAIGNIFY_KEY}"],
      "env": {"CAMPAIGNIFY_KEY": "YOUR_CAMPAIGNIFY_KEY"}
    }
  }
}

Make an API key

  1. In the app, open Settings, MCP access.
  2. Name the key and pick Read only or Read and write.
  3. Copy the key. It is shown once. We store only a fingerprint of it.

A key works in your workspace as you until you revoke it. Send it as Authorization: Bearer <key>.

Ad platform playbooks

Ask Claude to set up, launch or improve ads on Google Search, Meta, TikTok, YouTube, LinkedIn, Pinterest, Snapchat, Reddit or X. It loads that platform's playbook with get_ad_playbook and goes through it with you: account setup with official links, making the ads in Campaignify, a launch checklist (copy, images, logo, sitelinks, tracking, AI labels, policies) and what to check after launch.

The same tool has a playbook for each Campaignify job: UGC video ads, image ads, ad copy, campaign plans, landing pages, lead follow-up by email and text (with the consent and sending rules), and SEO, AEO and GEO.

Mr. Campaign, your marketing consultant

Type /consultant (in apps that show the connector's commands) or ask Claude for Mr. Campaign. He learns your business from your Campaignify workspace, finds the one thing holding sales back (the offer, leads, ads, content, pricing or the funnel) and ends with your next 3 moves. He's an AI character: he never invents results or promises outcomes, and asks before anything spends credits.

Using Claude without the connector? Download the same playbooks and Mr. Campaign as Claude skills, one folder each.

Rules it follows

  • Costs are in credits and shown before anything is made. Image ads and videos are made only with the exact total from the quote.
  • It uses your plan's tools and your credits, with the same compliance checks as the app.
  • Videos need a confirmed email, as in the app.
  • AI presenters are AI-generated people, never real ones.

Troubleshooting

  • It asks me to log in again and again. Log in to campaignify.ai in the same browser first, then connect.
  • "This connection is read-only." You connected read only. Remove the connector in Claude and add it again, choosing read and write, or use a read and write key.
  • "The price changed, nothing was made." A quote is only good for the exact settings you priced. Ask Claude to quote again, then agree to the new total.
  • Not enough credits, or a tool isn't on my plan. Ask Claude for your account status. Credit packs and plans are bought in the app under Billing.
  • Videos won't start. Videos need a confirmed email. Confirm it from the email we sent, or resend it in the app.
  • The logo or the tool list looks out of date. Claude saves a connector's details when you add it. Remove it and add it again.
  • Too many requests. Each key or connection gets 120 requests and 30 changes a minute. Wait a minute and ask again.
