Set it up

Two minutes, no code.

You need a Campaignify account and Claude on any plan. On the Free plan, Claude allows one custom connector.

Claude on the web, desktop or phone

  1. In Claude, open Customize, then Connectors.
  2. Click + Add, then Add custom connector.
  3. Name it Campaignify, paste {{ url }} and click Continue.
  4. Keep the settings Claude detects and click Add.
  5. Log in to Campaignify and choose read only or read and write (read and write can spend credits).
  6. In a chat, click +, then Connectors, and switch Campaignify on.

Claude Team or Enterprise

  1. An owner opens Organization settings, then Connectors.
  2. Click Add, then Custom, then Web, and paste {{ url }}.
  3. Each member then finds Campaignify under Customize, Connectors and clicks Connect to log in with their own Campaignify account.

Claude Code

Add it, then run /mcp and pick Campaignify to log in:

claude mcp add --transport http campaignify {{ url }}

Prefer a key? Make one under Settings, API and Claude, and see the docs.

Questions

Good to know.

Does it cost extra?

No. Ads, copy and plans made from Claude use the same credits as in the app, and looking at your products and assets is free.

Can Claude spend my credits without asking?

Image ads and videos need the exact total from a quote, and Claude asks you before it makes them. You can also connect read only, or block single tools in Claude under Customize, Connectors.

Can it run my ads?

No. Campaignify makes the creative, copy and plan. You launch the ads in each platform's ads manager.

Which apps does it work with?

Claude on the web, desktop and phone, Claude Code, and other apps that support remote MCP servers. Setup for each is in the docs.

The logo or tools look out of date in Claude.

Claude saves a connector's details when you add it. Remove the connector and add it again to refresh them.

Claude is made by Anthropic. Campaignify is an independent app that connects to Claude through the Model Context Protocol (MCP), and isn't made or endorsed by Anthropic.
