Make ads from Claude

Connect Campaignify to Claude and ask in plain words. Claude shows you the credit total first, and nothing is made until you agree. It uses the same credits as the app.

Connect it

Claude on the web, desktop or phone, on any plan. On Claude's Free plan you can add one custom connector.

  1. In Claude, open Customize, then Connectors.
  2. Click + Add, then Add custom connector.
  3. Name it Campaignify, paste the server address and click Continue.
  4. Keep the settings Claude detects and click Add.
  5. Log in to Campaignify and choose read only or read and write (read and write can spend credits).
  6. In a chat, click +, then Connectors, and switch Campaignify on.
  1. An owner opens Organization settings, then Connectors.
  2. Click Add, then Custom, then Web, and paste the server address.
  3. Each member then finds Campaignify under Customize, Connectors and clicks Connect to log in with their own Campaignify account.

Then run /mcp in Claude Code and pick Campaignify to log in.{% if keys_on %} Prefer a key? Make one under MCP access.{% endif %}

Most apps that support remote MCP servers can add the server address and sign in. If yours only runs local servers, the mcp-remote bridge works with a key{% if keys_on %} from MCP access{% endif %}; the config is in the docs.
